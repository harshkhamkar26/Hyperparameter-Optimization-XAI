# Project Management

## Team Roles

| Role | Responsibility |
|---|---|
| Project Lead / Student | Overall development, integration and documentation |
| ML Developer | Model selection, training and optimization |
| XAI Developer | Explainability analysis and visualizations |
| Documentation & QA | SEPM documents, testing and traceability |
| Project Guide | Review, feedback and academic approval |

For a single-student project, these technical roles can be treated as responsibilities rather than separate people.

## Change Management
Any change to the problem statement, dataset, model, optimization method or major requirement should be recorded with:
1. Change description
2. Reason
3. Impact on requirements/design
4. Approval or review
5. Updated documentation

## Configuration Management
GitHub is the version-control repository. Requirements, UML, design documents and implementation changes should be committed with meaningful messages.

## Communication
Progress should be reviewed at project milestones with the project guide. Major decisions should be recorded in the project documentation.

## Quality Management
Quality will be maintained through requirements traceability, peer/guide review, testing, reproducible experiments, consistent documentation and version control.
