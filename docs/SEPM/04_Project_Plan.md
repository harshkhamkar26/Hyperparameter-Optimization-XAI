# Project Plan

## Development Phases

| Phase | Activities | Deliverable |
|---|---|---|
| 1. Requirements | Problem definition, scope, stakeholders, requirements | SRS |
| 2. Feasibility | Technical, economic, operational and schedule analysis | Feasibility Study |
| 3. System Design | Architecture and UML modelling | Design + UML |
| 4. Data Preparation | Dataset collection, cleaning and preprocessing design | Prepared dataset specification |
| 5. Baseline Model | Train initial model and establish baseline metrics | Baseline results |
| 6. Optimization | Define search space and run optimization | Best hyperparameters |
| 7. XAI | Generate global and local explanations | XAI results |
| 8. Testing | Functional, data, model and reproducibility testing | Test report |
| 9. Documentation | Compile results, limitations and conclusions | Final report |
| 10. Presentation | Demonstration and viva preparation | Final presentation |

## Milestones
- M1: Requirements approved
- M2: UML/design approved
- M3: Dataset finalized
- M4: Baseline model completed
- M5: Optimization completed
- M6: XAI completed
- M7: Testing completed
- M8: Final documentation completed

## Version Control
GitHub will be used to maintain project history. Major milestones should be represented by meaningful commits and tagged releases when appropriate.
