# Feasibility Study

## 1. Technical Feasibility
The project is technically feasible using Python and open-source machine-learning libraries. Scikit-learn provides standard ML algorithms and evaluation utilities, Optuna can perform automated hyperparameter optimization, and SHAP can provide model explanations. The workflow can be developed on a normal student laptop for a moderate-sized dataset.

**Result:** Feasible.

## 2. Economic Feasibility
The proposed software stack is open source. A public dataset can be used, so the project does not require paid datasets or commercial software.

**Result:** Feasible at minimal cost.

## 3. Operational Feasibility
The workflow is designed for students, analysts and project evaluators. Outputs such as metrics, charts and feature explanations can be presented in an understandable form.

**Result:** Feasible.

## 4. Schedule Feasibility
The project can be divided into requirements, design, implementation, experimentation, testing and documentation phases. Work can be completed incrementally and tracked through GitHub commits.

**Result:** Feasible with milestone-based planning.

## 5. Legal/Ethical Feasibility
Only public datasets with appropriate usage rights should be selected. Sensitive personal information should not be used unless there is a clear legal and ethical basis. Model limitations and explanation limitations must be documented.

**Result:** Feasible subject to dataset/license checks.

## Conclusion
The project is feasible technically, economically, operationally and academically, provided that the dataset and final ML problem are selected carefully.
