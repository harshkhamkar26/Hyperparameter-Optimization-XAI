# Research Pipeline

This folder contains the Jupyter-based research pipeline for the **Explainable, Imbalance-Aware Hyperparameter Optimization Framework for Robust Tabular Marketing Classification**.

## Current case study
- Dataset: UCI Bank Marketing Dataset
- Task: supervised binary classification
- Target: `y` (yes/no term-deposit subscription)
- Domain: marketing

## Research flow
1. Data understanding
2. EDA and imbalance analysis
3. Leakage-safe preprocessing
4. Baseline models
5. Baseline evaluation
6. Imbalance-handling experiments
7. Hyperparameter optimization
8. Objective comparison
9. Multi-objective HPO
10. Threshold optimization
11. Robustness analysis
12. Explainable AI with SHAP
13. Explanation stability
14. Final research comparison

The notebooks are intentionally separated so every experiment is reproducible and traceable for the research paper.
